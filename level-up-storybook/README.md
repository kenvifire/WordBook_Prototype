# Level Up Storybook

Build the landing page for "WordBook", a web app that helps English learners (A1–B2 level) read stories retold at their level. 

SCOPE

- Build ONLY the landing page at "/" plus a simple placeholder page at "/start" (text: "Sign-in coming soon"). No backend, no real authentication, no database.

- React + Tailwind + shadcn components. Mobile-first and fully responsive. Single scrolling page with smooth anchor navigation.

BRAND AND TONE

- Fun, playful, curious, a little mischievous. Like a friendly storyteller, never childish and never corporate.

- All page copy must be written in SIMPLE English (CEFR A2–B1): short sentences, common words, no idioms, no jargon. Learners will read this page.

- Tagline: "Learn the words. Then read the story."

VISUAL STYLE (very important)

- Flat, geometric vector illustration with a modern editorial feel. Characters are built from bold simple shapes (circles, triangles, rounded rectangles), with long, angular, slightly exaggerated limbs and small expressive faces. Layered, overlapping shapes create depth.

- Add a grainy, stippled "risograph" texture: soft gradients that fade into fine noise, used for shadows, smoke, clouds and glows. Implement it with an SVG feTurbulence noise filter or a CSS noise overlay (mix-blend-mode), reusable as a utility
